Pixel Value Arithmetic How Blending Modes Work

Most digital art software programs contain some form of blend modes to manipulate and combine two layers. Underneath the surface lie thousands of calculations made sequentially at high speeds — one per overlapping pixel.

Introduction

Blend modes allow for many effects that are specifically altered by the top layer and a certain blend tool, transforming the bottom layer. These modes allow for effects like recoloring, adding shadows and highlights, increasing contrast, and more.

By understanding the math behind blend modes, an artist can improve their eye for detail to achieve a desired effect with more intention. Every overlapping pixel between two layers undergoes an arithmetic calculation to output a new pixel value — based on the initial colors and which of the six general categories of blend mode is utilized.

RGB Values and General Calculation

Monitors exclusively utilize RGB values to determine pixel color and process it for calculation and display. Each value — red, green, and blue — has a numerical value stating the strength of that primary in the combined color. A monitor can have hundreds of thousands of pixels, each set with RGB values that, overall, create a picture on a display.

In all art software where the user can manipulate visuals, these RGB values will be frequently changed. When two layers overlap each other, they define a relationship that determines the output of the blend. The top, visible layer manipulates the bottom layer under a certain blend mode, with the modes associated with a formula to output new RGB values.

Each value is translated to be between 0 and 1, with each calculation being multiplied by 255 for the output. Any computations exceeding 1, below 0, or leaving a trailing decimal exceeding 2 decimal places are normalized to the closest value within the min-max.

In addition to the RGB pixel values being combined, another factor is considered: opacity. Opacity acts as a linear interpolation of the resulting blended pixels. This additional factor is called Alpha Compositing — the blend calculation itself is not impacted by opacity; rather, the resulting blend pixel is affected by opacity strength.

The Core Formula

The following is the basic equation to compute blending, including the top/blending layer, bottom/base layer, the blend mode function, and the opacity modifier. It is applied independently to each R, G, and B channel.

R  =  ( (1 − α) × B  +  f(B,T) × α )
Result  =  R × 255
α=Opacity of top layer (0–1)
B=Bottom (base) layer RGB value
T=Top (blend) layer RGB value
f(B, T)=Blend mode function
Applied independently for each R, G, and B channel.

Blend Mode Categories

There are six general categories of blend modes in Photoshop, containing 27 distinct modes in total.

Normal & Dissolve

Blending occurs only with the impact of opacity — no blend function equation is applied. Dissolve randomly scatters pixels based on opacity strength without altering RGB values.

NormalDissolve
Darken Modes

Selects the lower RGB value between layers per channel. Multiply multiplies both values together. Color Burn and Linear Burn increase contrast via division and subtraction. Darker Color compares composite luminosity.

DarkenMultiplyColor BurnLinear BurnDarker Color
Lighten Modes

Prioritizes higher RGB values to brighten highlights and midtones. Screen inverts, multiplies, then inverts again. Color Dodge and Linear Dodge (Add) brighten the base by dividing or adding. Lighter Color compares composite luminosity.

LightenScreenColor DodgeLinear DodgeLighter Color
Contrast Modes

Colors evaluated against the 50% gray midpoint — below darkens, above lightens. Overlay applies Multiply to darks and Screen to lights. Soft Light is gentler. Hard Light reverses the roles. Hard Mix posterizes.

OverlaySoft LightHard LightVivid LightLinear LightPin LightHard Mix
Comparative Modes

Compares top and base pixels mathematically. Difference subtracts and takes the absolute value, inverting colors. Exclusion lowers contrast. Subtract and Divide apply their respective operations per channel.

DifferenceExclusionSubtractDivide
HSL Modes

Operates on Hue, Saturation, and Luminosity rather than RGB. Hue applies the blend layer's hue to the base's saturation and luminosity. Saturation applies only saturation. Color applies both. Luminosity applies only luminosity.

HueSaturationColorLuminosity
